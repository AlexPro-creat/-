# Как запустить CRM в интернете через GitHub + Render

Это займёт 10–15 минут. Понадобится только браузер, ничего устанавливать на компьютер не нужно.

Смысл: GitHub — это место, где хранится код. Render — бесплатный сервис, который берёт код с GitHub и запускает его по постоянной ссылке, доступной с любого телефона и компьютера.

---

## Часть 1. Заливаем код на GitHub

**Шаг 1. Заведите аккаунт GitHub** (если его ещё нет)

Перейдите по ссылке и зарегистрируйтесь: **https://github.com/signup**

**Шаг 2. Создайте новый репозиторий (папку для проекта)**

Перейдите по ссылке: **https://github.com/new**

- «Repository name» — впишите, например: `cosmetics-crm`
- Остальное не трогайте (Public оставить как есть)
- **Не ставьте** галочку «Add a README file»
- Нажмите зелёную кнопку **«Create repository»**

**Шаг 3. Загрузите файлы CRM**

После создания репозитория откроется страница с инструкциями — на ней будет ссылка **«uploading an existing file»**, нажмите на неё. Либо просто откройте (заменив `ВАШ_НИК` на ваш логин GitHub):

`https://github.com/ВАШ_НИК/cosmetics-crm/upload/main`

Дальше:
1. Разархивируйте присланный вам файл `crm-project.zip` на компьютере (просто дважды кликните по нему).
2. Откройте разархивированную папку `crm-project`.
3. Выделите **всё содержимое папки** (все файлы и подпапки `src`, `public`, `data` и т.д. — но не саму папку `crm-project`) и перетащите их мышкой в окно браузера на странице загрузки GitHub.
4. Дождитесь, пока все файлы загрузятся (полоски прогресса исчезнут).
5. Внизу страницы нажмите зелёную кнопку **«Commit changes»**.

Готово — код теперь на GitHub.

---

## Часть 2. Запускаем CRM на Render

**Шаг 4. Зарегистрируйтесь на Render**

Перейдите по ссылке: **https://dashboard.render.com/register**

Проще всего нажать кнопку **«GitHub»** и войти тем же аккаунтом, что и в Части 1 — тогда Render сразу получит доступ к вашему репозиторию.

**Шаг 5. Создайте веб-сервис**

Перейдите по ссылке: **https://dashboard.render.com/select-repo?type=web**

- Найдите в списке репозиторий `cosmetics-crm` и нажмите рядом с ним **«Connect»**
  (если список пуст — нажмите «Configure account» и разрешите Render доступ к репозиторию)

**Шаг 6. Настройте параметры запуска**

На открывшейся странице настроек:

- **Name** — любое имя, например `cosmetics-crm`
- **Region** — можно оставить по умолчанию, или выбрать ближайший (например, Frankfurt)
- **Branch** — `main`
- **Build Command** — оставьте **пустым** (стереть, если что-то написано)
- **Start Command** — впишите: `npm start`
- **Instance Type** — выберите **Free** (бесплатный), чтобы для начала посмотреть, как всё работает

Нажмите зелёную кнопку внизу страницы **«Create Web Service»**.

**Шаг 7. Дождитесь запуска**

Render начнёт сборку — это видно в чёрном окне логов на экране. Когда там появится строка `CRM запущена`, всё готово (обычно 1–3 минуты).

Вверху страницы будет ссылка вида `https://cosmetics-crm-xxxx.onrender.com` — это и есть постоянный адрес вашей CRM. Откройте его.

**Шаг 8. Войдите и смените пароли**

Логин администратора: `admin@cosmedica.local`, пароль: `admin123`.

Готовые аккаунты команды (у всех сразу же смените пароли во вкладке «Команда» — удалить и создать заново с тем же именем и e-mail, но своим паролем):

## Важно про бесплатный тариф Render

- Если сайтом никто не пользуется 15 минут, Render «засыпает» — следующее открытие займёт 30–50 секунд, пока сервис проснётся. Это нормально, не ошибка.
- **Данные могут обнуляться** при обновлении или перезапуске сервиса — на бесплатном тарифе диск не гарантированно сохраняется. Это касается и списка клиентов/задач (`data/db.json`), и загруженных в задачи фото/аудио (`data/uploads/`). Для тестирования это не страшно, но **для реальной работы с клиентами так рисковать нельзя**.

### Чтобы данные не терялись (для реальной работы)

Нужно включить платный план с постоянным диском:

1. В панели Render откройте ваш сервис → вкладку **Settings** → в блоке **Instance Type** выберите **Starter** (от $7/мес).
2. Затем перейдите во вкладку **Disks** этого же сервиса и нажмите **Add Disk**:
   - Mount Path: `/opt/render/project/src/data`
   - Size: 1 GB (более чем достаточно — здесь же будут храниться и вложения к задачам)
3. Сохраните — Render перезапустит сервис уже с постоянным хранилищем.

Подробности от самого Render: **https://render.com/docs/disks**

## Что дальше

**Обновление кода/логики.** Если я пришлю обновлённый архив — просто повторите Часть 1 (загрузите новые файлы поверх старых тем же способом), и Render автоматически пересоберёт и перезапустит сайт сам, без дополнительных действий.

**Обновление данных по продажам/долгам.** Когда появятся свежие выгрузки — загрузите их в папки на Google Диске, созданные для этого (продажи / долги), и напишите об этом в разговоре с Claude в этом проекте. Вам придёт обновлённый архив с пересчитанным регулярным ассортиментом и долгами — залейте его тем же способом (Часть 1), уже сохранённые вами карточки клиентов и пароли не потеряются.

Если что-то не получается на каком-то шаге — пришлите скриншот, разберёмся.
